# HIFT: instrumento y significado del objetivo

El [artículo original](https://pmc.ncbi.nlm.nih.gov/articles/PMC12049098/) enlaza expresamente el [dataset público](https://doi.org/10.6084/m9.figshare.25858906.v1). Describe CR10, preguntada 30 minutos después del ejercicio para representar la sesión completa. El pulso publicado es la media o el máximo del entrenamiento. AMRAP, FOR TIME y EMOM son sesiones separadas, con descanso de 72 horas entre días de entrenamiento; no son tres respuestas dentro de una caminata.

El workbook conserva 28 identificadores y 81 respuestas numéricas: 28 AMRAP, 28 FOR TIME y 25 EMOM. Las tres ausencias EMOM se conservan. El artículo y el repositorio describen 25 personas; no se eliminan tres identidades ni se imputan respuestas para igualar ese número.

Aunque el instrumento sea CR10, el objetivo de sesión difiere de Borg momentánea. Estas respuestas quedan fuera de una unión directa de etiquetas nativas. Una tarea auxiliar futura tendría que conservar esa diferencia, su ventana de pulso y las 28 identidades originales. No hay reportes previos dentro de cada entrenamiento ni relojes exactos publicados; no se inventan.
